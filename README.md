# 雨课堂视频自动播放助手

在 Chrome 中依次播放雨课堂课程目录里的未完成视频。脚本通过网页播放器操作，等页面确认完成后才切换下一段；作业和考试由用户自己处理。

东南大学 2026 秋《人工智能通识导论》的课后习题与考试答案整理见[习题答案文档](docs/人工智能通识导论习题答案.md)。题目选项顺序可能变化，请按答案内容核对。

播放页右上角有可拖动、可折叠的状态卡片，显示当前视频、播放时间、倍速、已完成数量和运行状态。

## 准备

- 安装 [Node.js](https://nodejs.org/) 20 或更高版本。
- 安装 Google Chrome。
- 准备课程的「学习内容」链接，地址通常以 `/studycontent` 结尾。

不需要把雨课堂账号、密码或 GitHub Token 写进脚本。

## 快速开始

1. 下载仓库并安装依赖：

   ```bash
   git clone https://github.com/zja2004/yuketang-daishuajiaoben.git
   cd yuketang-daishuajiaoben
   npm install
   ```

2. 从浏览器地址栏复制课程「学习内容」的完整链接，运行：

   ```bash
   npm start -- --url "https://学校域名.yuketang.cn/pro/lms/课程编号/课程ID/studycontent"
   ```

   请把示例地址替换为自己的真实课程链接。Windows PowerShell、macOS 终端和 Linux 终端均可使用上述双引号写法。

3. 首次运行会打开一个独立的 Chrome 窗口。在这个窗口中**手动登录**雨课堂，完成页面要求的验证，进入课程。脚本会等待课程目录出现，再从第一段未完成视频开始播放。

4. 保持 Chrome 窗口和命令行窗口打开。进度会显示在浏览器悬浮卡片和命令行中。需要停止时，在命令行按 `Ctrl+C`。

5. 下次运行相同命令即可续播；脚本会读取网页目录中的完成状态，跳过已完成视频。

## 常用命令

把以下示例中的 `课程链接` 换成步骤 2 复制的完整链接：

```bash
# 只查看视频目录及完成状态
npm start -- --url "课程链接" --list

# 只播放一段，适合先验证课程是否兼容
npm start -- --url "课程链接" --limit 1

# 尝试使用播放器提供的 1.5 倍速
npm start -- --url "课程链接" --speed 1.5
```

`--speed` 默认是 1，可选 0.5、1、1.25、1.5、2。课程如果强制重置倍速，脚本会提示并按实际速度播放，不会伪造进度。

如果已有通过 Chrome DevTools Protocol 启动的浏览器，脚本默认尝试连接 `http://127.0.0.1:9339`；也可以用 `--cdp` 指定地址。普通用户无需设置这个选项，脚本会自行打开独立 Chrome。

## 悬浮状态卡片

- 拖动卡片顶部可移动位置。
- 点击右上角的 `−` 可以折叠，再点击 `+` 展开。
- 卡片显示「等待脚本更新」时，检查命令行是否已停止或浏览器是否断开。
- 视频进度条表示当前视频播放位置；「已完成」数量以课程网页的确认状态为准。

## 遇到问题

| 现象 | 处理方法 |
| --- | --- |
| 一直显示登录页 | 在脚本打开的 Chrome 窗口里手动登录，并完成验证码或滑块验证。 |
| 提示「课程页没有未完成视频」 | 确认链接指向课程的「学习内容」页，并检查是否还有未完成的视频。 |
| 提示「视频停滞超过 90 秒」 | 检查网络、网页弹窗和播放器，再重新运行原命令。 |
| 视频播完但页面没有确认完成 | 查看网页是否有额外任务或提示；脚本会停下，避免误报。 |
| 倍速被重置 | 这是课程播放器的限制，使用 1 倍速即可。 |

## 隐私与开发

登录状态保存在本机的 `.browser-profile/`，依赖放在 `node_modules/`；两者均已被 `.gitignore` 排除。不要把浏览器配置、Cookie、账号信息或 Token 手动提交到仓库。

实现位于 `src/index.js`，悬浮界面位于 `src/overlay.js`。脚本依赖当前雨课堂网页的目录和播放器结构，平台改版后可能需要调整选择器。它只操作网页播放器，不直接调用课程进度接口。
